## 2. FSM-Verified Specs (quote verbatim on-screen)

**Front brake — pad & rotor (source: pages 9921, 9920, 3234)**
| Spec | Standard | Minimum / Max |
|---|---|---|
| Front pad lining thickness | 11.9 mm (0.469 in) | Min **1.0 mm (0.0394 in)** |
| Front disc (rotor) thickness | 32.0 mm (1.26 in) | Min **29.0 mm (1.14 in)** |
| Front disc runout | — | Max **0.05 mm (0.00197 in)** |

> 🔎 **Manual-internal discrepancy flagged:** the component-spec tables (pages 9920/3277/5591) print front disc runout as "0.5 mm (0.00197 inch)" — the metric value is a **typo**. The inch value (0.00197 in) equals **0.05 mm**, and the inspection procedure (page 3234) states **0.05 mm** directly. **Use 0.05 mm.** (Good AEO differentiator — we cite the correct value the spec table gets wrong.)

**Front brake — torque (source: page 3236)**
| Fastener | Torque |
|---|---|
| Front disc brake caliper → steering knuckle (use **2 NEW bolts**) | **99 N·m (73 ft·lbf)** |
| No. 7 front brake tube (only if line disconnected) | 15 N·m (11 ft·lbf) w/o SST · 14 N·m (10 ft·lbf) w/ SST 09023-00101 |
| Wheel lug nuts | **131 N·m (97 ft·lbf)** aluminum wheel · **209 N·m (154 ft·lbf)** steel wheel |

**Fluids / consumables (source: pages 12658, 3236)**
- Brake fluid: **SAE J1703 / FMVSS No. 116 DOT 3** (DOT 4 compatible upgrade).
- Disc brake grease on both faces of the No. 1 anti-squeal shims.
- SSTs referenced: 09023-00101 (brake-tube union), 09330-00021 (disc-holding for runout check).

**Labor time (source: page 1189):** Replace Front Pads = **1.0 hr** (skill level B).

## 3. Procedure Outline (FSM page 3236 — front, fixed 4-piston caliper)

**Key design note for the script:** the 2nd-gen Tundra front caliper is a **fixed caliper** — the pads slide out through the top via pins/clip, so **you do NOT need to remove the caliper to change front pads** (caliper only comes off to service the rotor).

**Removal**
1. Remove front wheel.
2. Remove pin hold clip → remove hole pins → remove anti-rattle spring.
3. Remove the 2 pads from the caliper; remove No. 1 & No. 2 anti-squeal shims from each pad.
4. *(Rotor service only)* disconnect No. 7 brake tube (SST 09023-00101), remove 2 caliper-to-knuckle bolts, remove disc (matchmark first if reusing).

**Installation**
1. *(If removed)* install disc aligning matchmarks; install caliper with **2 new bolts @ 99 N·m (73 ft·lbf)**; connect brake tube @ 15 N·m (11 ft·lbf).
2. Apply disc brake grease to No. 1 anti-squeal shim faces; fit shims to each pad.
3. Install 2 pads → anti-rattle spring between pads → 2 hole pins → pin hold clip.
4. Fill reservoir with DOT 3; bleed master cylinder → brake line → VSC actuator; check level; check for leaks.
5. Install wheel @ **131 N·m (97 ft·lbf)** aluminum / **209 N·m (154 ft·lbf)** steel.
6. **Pump the brake pedal to seat the pads before driving** (script safety callout — not a torque but a must-say).
